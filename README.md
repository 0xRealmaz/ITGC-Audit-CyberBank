# IT General Controls (ITGC) Audit – CyberBank Demo Environment

##  Project Overview
This project simulates a real-world IT General Controls (ITGC) audit for a fictional financial organization named **CyberBank Demo Environment**.

The goal is to evaluate the effectiveness of key IT controls and identify security and operational weaknesses.

---

##  Objectives
- Assess IT General Controls (ITGC)
- Perform control testing across key domains
- Identify audit findings and associated risks
- Provide remediation recommendations
- Demonstrate IT Audit and GRC skills

---

##  Project Structure

- 01-Audit-Plan.md → Defines audit scope and objectives  
- 02-Control-Testing.md → Control testing results (Pass/Fail)  
- 03-Audit-Findings.md → Detailed audit findings  
- 04-Evidence-Summary.md → Supporting evidence for findings  
- 05-Final-Report.md → Executive summary and final opinion  

---

##  Audit Scope

The audit covered the following IT control areas:

- Access Management
- Authentication Controls
- Change Management
- Backup & Recovery
- Logging & Monitoring

---

##  Key Findings

- Weak Access Control (No RBAC)
- No Multi-Factor Authentication (MFA)
- Lack of Backup Strategy
- No Logging or Monitoring System
- Weak Change Management Controls

---

##  Overall Conclusion

The IT General Controls environment was assessed as:

> **Ineffective**

This indicates significant control weaknesses that expose the organization to operational and security risks.

---

##  Recommendations

- Implement Role-Based Access Control (RBAC)
- Enable Multi-Factor Authentication (MFA)
- Deploy centralized logging and monitoring (SIEM)
- Establish automated backup and recovery processes
- Implement formal change management procedures
