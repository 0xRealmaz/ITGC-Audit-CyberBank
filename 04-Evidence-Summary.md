# Evidence Summary – CyberBank IT Audit

## Overview
This document provides supporting evidence for the audit findings identified during the ITGC audit of CyberBank Demo Environment.

---

## Finding 1: Weak Access Control

**Evidence:**
- User access review shows multiple accounts with admin-level privileges
- No Role-Based Access Control (RBAC) configuration observed
- Sample user list indicates excessive permissions granted

---

## Finding 2: Lack of Multi-Factor Authentication

**Evidence:**
- Authentication system relies only on username and password
- No MFA configuration settings available in system settings
- Login process does not request second authentication factor

---

## Finding 3: No Backup Mechanism

**Evidence:**
- No backup schedules found in system configuration
- No backup logs or backup reports available
- No evidence of backup storage or recovery testing

---

## Summary

The evidence collected supports the audit findings and confirms the absence of key IT General Controls within CyberBank environment.
